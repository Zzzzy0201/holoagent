name: navigation
description: |
 控制机器人从当前位置导航到预设位置（点位、人物或物品），仅支持allwed_targets中的对象。
 **适用场景：**
  - 用户明确说明去某个点位，如“去点位1”。
  - 任务需要前往某个点位才能完成，如“拿”。
 **使用规则：**
  - 如果指令包含“拿”、“取”、”想要“等拿取含义，需导航至物品的点位，完成拿取动作后导航至返回点。返回点的确定规则：默认为用户处，若指令中包含”给“、”放到“等递送含义，递送的对象所在处就是返回点。
  - 如果用户说“拿回来“、”送回来“，完成夹取后导航至用户位置。
  - 如果用户命令包含“拿回去”、“归位”等含义，完成夹取后导航至物体的默认存放地。
  - 如果用户指明了物品的具体位置（如“点位1的苹果”），导航至该具体位置（如“点位1”）。注意：当且仅当位置词与物品存在直接语法修饰关系时需要运用本条规则。
  - 本技能只负责移动，并不包含夹取等手部动作。
  - 禁止输出不在以下allowed_targets中的对象。
allowed_targets:
 - one_point_1
 - one_point_2
 - one_point_3
 - one_point_4
 - user
 - people_1
 - people_2
 - apple
 - banana
 - mango
 - cola
 - coffee
 - basket
