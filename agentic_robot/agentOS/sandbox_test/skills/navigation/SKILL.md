name: navigation
description: |
 控制机器人从当前位置导航到预设位置（点位、人物或物品）。
 **适用场景：**
  - 用户明确说明去某个点位，如“去点位1”。
  - 任务需要前往某个点位才能完成，如“拿”。
 **使用规则：**
  - 如果指令包含“拿[物品]”、“我想要[物品]”等拿取含义，需要导航至物品点位，完成拿取动作后也需要导航至返回点放下。默认返回点为用户处。
  - 如果用户说“拿回来“、”送回来“，完成夹取后导航至用户位置。
  - 如果用户命令包含“拿回去”、“归位”等含义，完成夹取后导航至物体的默认存放地。
  - 如果用户指明了物品的具体位置（如“点位1的苹果”），导航至该具体位置（如“点位1”）。注意：当且仅当位置词与物品存在直接语法修饰关系时需要运用本条规则。
  - 本技能只负责移动，并不包含夹取等手部动作。
allowed_targets:
 - point_1
 - point_2
 - point_3
 - point_4
 - user
 - people_1
 - people_2
 - apple
 - banana
 - mango
 - cola
 - coffee
 - basket
